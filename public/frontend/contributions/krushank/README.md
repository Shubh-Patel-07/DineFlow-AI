## Technical Overview

The Menu Manager module allows restaurant staff and admins to view, add, edit, and categorize dish menu items with custom prices, tags, and category filters.

### Key Components Built

1. **`menu-manager.html`**:
   - Menu items layout grid with category filter tabs.
   - Add/Edit Item modal form with image URL, price, category, and tax rates.

2. **`menu-manager.js`**:
   - CRUD API integration with Laravel `/api/menu` endpoints.
   - Dynamic DOM rendering and search filter event listeners.

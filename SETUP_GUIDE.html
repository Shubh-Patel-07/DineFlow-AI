Quick Start

Step 1: Navigate to Project

cd F:\Laravel\NEWPOS\RePOS

Step 2: Start Server

php artisan serve --port 8000

Step 3: Open in Browser

Visit http://localhost:8000/login

✓ Ready to Go! The migration and database seeding are already complete.

Session Management

  • Session persists across pages
  • Cleared on logout

URL Purpose

Common Issues

  • Server won't start? Check if port 8000 is available
  • Login fails? Verify database migration ran successfully
  • PIN login not appearing? Clear browser cache and login again
  • Database issues? Run php artisan migrate:refresh --seed
